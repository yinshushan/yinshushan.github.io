# 生产集成清单

本地后端已经定义完整业务接口与模拟交易链路。以下项目需要真实平台凭据、云资源或运营配置，不能在本地代码中伪造完成。

## 微信小程序

1. 在服务端调用 code2Session，用 `js_code` 换取 openid/session_key。
2. AppSecret 只能保存在服务端密钥管理中，不得下发给小程序。
3. 手机号授权需使用用户操作产生的动态 code，并在服务端换取手机号。
4. 订阅消息需配置模板 ID，并仅在用户明确触发授权后发送。

## 微信支付 v3

1. 配置商户号、API v3 密钥、商户证书序列号和商户私钥。
2. `/v1/payments` 在生产模式中应调用 JSAPI 下单，返回真实的 `prepay_id` 和小程序调起支付参数。
3. `/v1/payments/wechat-notify` 必须校验平台证书签名、解密回调资源，并按商户订单号幂等处理。
4. 只有经过验签的成功回调才能将订单改为已支付并扣减库存。
5. 退款需增加真实退款单、回调和资金对账。

## 跨境与物流

1. 为每个目的国配置限运品、茶叶检疫、税费和报关规则。
2. 收件人身份信息属于敏感数据，应加密存储、最小化采集并设置删除周期。
3. 将运费试算从种子费率替换为实时物流报价。
4. 发货后将承运商回调转换为统一轨迹事件。

## CRM、私域与直播

1. 将会员等级、茶分和优惠券事件同步到 CRM，同步消息必须幂等。
2. 企业微信群活码应由运营后台配置有效期和人群标签，不在代码中硬编码。
3. 直播间 ID、回放地址和预约提醒需与所选平台同步。
4. 公众号文章可由 CMS 发布摘要，并使用微信允许的跳转方式。

## 数据库与安全

1. 将 JSON 持久化替换为 PostgreSQL/MySQL，将令牌、秒杀锁和幂等键放入 Redis。
2. 对库存扣减、支付确认、优惠券核销和茶分入账使用数据库事务。
3. 运营端不应长期使用单一 API Key；正式版应使用账号体系、RBAC、MFA 和审计日志。
4. 增加限流、WAF、结构化日志、指标、告警、备份、恢复演练和隐私数据删除流程。
5. 上线前完成支付、隐私、跨境数据和茶叶销售所需的法务/合规审查。
