# 予茶微信小程序

一个以“数字化转型的新茶道”为核心理念的原生微信小程序前端。主页使用大幅云雾茶山图像、宋体标题和极简双入口，内容围绕会员增长、私域运营、品牌内容、跨境电商和跨界合作展开。

## 已实现

- 首页沉浸式品牌主视觉、入会领礼和跨境选茶入口
- 新人券、拼团、秒杀、茶分兑礼等精准营销触点
- 茶叶分类筛选、产品卡片和跨境直邮入口
- 直播预告、茶友社群和公众号慢读入口
- 品牌故事、产地溯源和茶文化内容卡片
- 茶器、健康茶食等“茶生活”跨界合作专区
- 入会状态、茶分和优惠券的本地缓存演示
- 原生 tabBar 与四个完整页面

## 在微信开发者工具中打开

1. 打开微信开发者工具，选择“导入项目”。
2. 项目目录选择本文件夹 `yu-tea-miniprogram`。
3. 首次预览可使用测试 AppID；发布前在 `project.config.json` 中换成已认证的小程序 AppID。
4. 编译后可直接浏览四个 tab，体验入会、分类选茶、直播预约与个人中心交互。

## 上线前需对接

当前项目是可运行的前端原型，展示数据与营销状态为本地模拟。正式上线时建议对接：

- 微信登录、手机号授权与自有 CRM/会员系统
- 微信支付、订单、库存、拼团、秒杀和优惠券后台
- 小程序直播、客服消息、订阅消息和企业微信社群
- 产品批次溯源数据库与跨境物流查询
- 运营后台的内容发布、活动配置和用户分群

## 目录

- `pages/home`：品牌首页与私域增长入口
- `pages/shop`：选茶与跨境电商
- `pages/community`：直播、社群与内容
- `pages/me`：会员资产与订单入口
- `assets/images`：原创茶山、茶席和产地摄影素材
- `assets/icons`：基于 Radix Icons 导出的 tabBar 图标
